cockpit visual identity

Visual identity

cockpit inherits postern's paper-and-ink system: a monochrome canvas with a single ink foreground, right angles throughout, and colour reserved entirely for meaning. An infra dashboard is a dense field of state — when only the failing thing is red, the eye finds it without being taught where to look.

The mark

An attitude indicator

The instrument a pilot reads first: a viewport, a horizon, and the aircraft symbol sitting on it. It answers one question — am I level? — which is exactly the question cockpit answers about a fleet.

Drawn as a square rather than the traditional circle, so it belongs to a system with no rounding anywhere. Built entirely from rectangles on a 32-unit grid: no curves, no gradients, no optical corrections. It is the same object at 16 px and at 160 px.

Below 20 px the mark switches to a simplified cut: the centre pip is dropped, the bezel thickens, and the bars widen. Same silhouette, fewer parts to mush. That variant is mark-small.svg and is what the favicon uses.

Banked — the alert state
→

The horizon banks when the fleet is unhealthy. A real instrument behaviour used as a status channel: the logo in the nav is itself a health indicator, so the product's own chrome tells you something is wrong before you read a word.

Used sparingly — banked is only for an active alert, never decoration, and never in marketing or the favicon.

Lockup

Always lowercase. Schibsted Grotesk 600, tracking −0.035em. The mark is set to 1em and separated by 0.44em, so the lockup scales as one object and never needs re-drawing.

do
  • Set the mark in currentColor so it inherits ink.
  • Use the bare mark wherever the word "cockpit" already appears nearby.
  • Give it clear space of at least half the mark's width on every side.
don't
  • Colour the mark with a semantic accent — except banked, in danger.
  • Capitalise, letterspace, or set the wordmark in another face.
  • Round the corners, add a gradient, or place it on a coloured tile.

Colour

The canvas. Everything sits on it.

ink
The single foreground, used at alpha for every grey.

There is no grey palette. Every neutral is ink at an alpha step, so the whole greyscale re-derives itself correctly when the theme flips.

Colour carries meaning, and nothing else

TokenMeansAppears as
accent healthy · running · applied Status dots, applied plans, passing healthchecks.
info pending · planning · neutral action Plans awaiting approval, in-flight applies.
warn degraded · nearing a limit Restart loops, disk pressure, expiring certs.
danger failed · unhealthy · destructive · firing Failed plans, dead containers, destructive impact.
ink/20 stopped · unknown · disabled Deliberately absent of colour — nothing to react to.

Coolify's dashboard colours nearly everything, so nothing stands out. Here, a screen with no colour on it means a fleet with nothing wrong — and that is the most common state, so most of the time cockpit is entirely monochrome.

Identity tint

A stable hue derived from each server's and app's name, used only for identification — never status. It lets a log line or a resource row be placed at a glance without introducing a second colour system. Lightness and chroma come from the theme, so tints stay quiet on paper and lift on graphite.

Anything the machine produced: ids, digests, domains, durations, env keys, log lines, cron expressions. If you could copy-paste it into a terminal, it is mono.

The split is a rule, not a preference: mono means "this is a literal value" and sans means "this is language about it." It removes an entire class of ambiguity in a UI that shows both constantly.
